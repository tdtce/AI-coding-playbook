## Как сэкономить?

Какие есть варианты не разориться на ИИ-инструментах, если вы кибер-бомж без подписки за 200 баксов:

- У **Windsurf** есть бесплатный уровень, его часто используют для автокомплита
- Можно достаточно бюджетно пользоваться **Roo Code** или **Cline** - на Reddit полно советов
- **Aider** очень экономно расходует токены по сравнению с другими инструментами
- **Codex CLI** и плагин для IDE входит в подписку ChatGPT (но может потребоваться настройка для работы через VPN)

Не всегда самая дешёвая модель - лучший выбор. Иногда дешёвая модель будет ходить по кругу 10 раз и в итоге потратит больше токенов, чем одно удачное решение на дорогой модели.

**Правило:** для критичных задач лучше переплатить за качественную модель, чем потратить часы на отладку результатов дешёвой.

**Апдейт правила от октября 2026:** хватит жадничать. Купите себе нормальную подписку или выбейте у работодателя. Жить сейчас без постоянного доступа к топовым моделям - зачем, как?

Не забывайте, что подписки на данный момент [намного выгоднее](https://she-llac.com/claude-limits), чем использование по API.

В BYOK-инструментах огромное значение имеет выбор моделей, разброс гигантский. Вот текущие цены моделей Claude по API за миллион входных и выходных токенов:

| Модель | Входные токены | Выходные токены |
|--------|---------------|-----------------|
| Claude Fable 5.1 | $10 | $50 |
| Claude Opus 5.5 | $4 | $20 |
| Claude Sonnet 5.5 | $2 | $10 |
| Claude Haiku 5.5 | $0.10 ($0.50 для промптов свыше 100K) | $0.50 ($2.50) |

Цены моделей других вендоров меняются слишком часто, актуальные смотрите на [OpenRouter](https://openrouter.ai/models) - разброс между топовыми и дешёвыми моделями там в сотни раз.

## Дополнительные лайфхаки для экономии

### Бесплатные модели на OpenRouter

Да, есть лимиты, могут отвечать медленно, но как один из вариантов. Список бесплатных моделей постоянно меняется, а если не хочется выбирать вручную, есть авто-роутер [`openrouter/free`](https://openrouter.ai/openrouter/free) - он сам случайно подбирает одну из бесплатных моделей под запрос, с учётом нужных возможностей (tool calling, картинки, structured output).

### Новые модели в cloak-режиме

Часто дают бесплатно попробовать как на OpenRouter, так и в Cursor.

## Заканчиваются лимиты, что делать?

1. Запустить [скрипт анализа токенов](https://gist.githubusercontent.com/kieranklaassen/7b2ebb39cbbb78cc2831497605d76cc6/raw/67757480772435a2b518de8349149f0aa5906250/token_analysis.py), скормить отчёт Claude Code и попросить найти плохие паттерны использования
2. Проверить в пустой сессии `/context` - не жрут ли много токенов какие-нибудь MCP и плагины
3. Если задача несложная, выставить `/effort low` или переключиться на Sonnet. У Opus 5.5 по умолчанию и так medium, так что поднимать стоит только для сложных задач
4. Используйте `/rewind` - например, если дискуссия пошла не туда или нужно отредактировать промпт
5. Если используете много тяжёлых MCP-вызовов, попробуйте плагин [context-mode](https://github.com/mksglu/context-mode)
6. Если сессия долго простаивает, Claude Code сам сжимает её прямо перед тем, как истечёт кэш (примерно через час), чтобы потом не платить за повторную загрузку всей истории (idle compaction). Срабатывает на сессиях от 200 тысяч токенов, порог меняется через `CLAUDE_CODE_IDLE_COMPACT_MIN_TOKENS`, а выключается `"idleCompaction": false`. Мы оставили её включённой на уровне организации
7. Меньше вайбкодить с 16 до 22 по Москве - это пиковые часы Claude Code, в которые лимиты уходят быстрее

## Fusion Router

Если ситуация обратная - задача критичная, то у OpenRouter есть [Fusion Router](https://openrouter.ai/docs/guides/routing/routers/fusion-router) - он прогоняет запрос через панель из нескольких моделей (по умолчанию Claude Opus + GPT + Gemini), затем модель-судья сравнивает их ответы (где сходятся, где расходятся, что упустили), и финальный ответ пишется уже с учётом этого разбора. Утверждают, что по качеству такая схема сравнима с Mythos.

## Локальные модели

> **Не рекомендуем:** Локальные модели годятся только для простейших задач. Они значительно уступают облачным моделям в качестве решения кодинговых задач. Ну разве что вы можете развернуть какой-нибудь Kimi K2 у себя.
